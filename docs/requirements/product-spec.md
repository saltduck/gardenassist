# 产品说明：养护计划名称

养护计划可以有自己的名称。执行计划并记入养护记录时，记录展示该名称。没有名称的记录继续展示任务类型。

## 数据

- `care_schedules.name`、`care_schedule_templates.name`：计划名称，非空。空值在写入时回落到任务类型中文标签。
- `care_logs.name`：执行当时的名称快照，可空。
- `care_logs.schedule_id`：来源计划的对外 id（`plant:` 或 `tpl:` 前缀），可空。手动记录不写。

## 行为

- 计划、待办、日历到期项展示计划名称。
- 养护记录各展示面：`name` 有内容时用名称，否则用任务类型中文标签。
- 到期日：优先用来源计划 id 匹配完成记录；仅当记录没有来源 id 时，才按任务类型匹配。
