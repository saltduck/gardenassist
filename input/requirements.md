# 需求备忘

## 养护计划名称

养护计划（植株专属 `care_schedules` 与同品种共享 `care_schedule_templates`）新增名称字段。

### 范围

- 新建、编辑养护计划时可以填写名称。名称为空时，用任务类型的中文标签作为名称（浇水、施肥、修剪、换盆、除虫、其他）。
- 已有计划在迁移时按任务类型回填同样的中文标签。
- 计划列表、待办、日历中的到期任务，展示计划名称。
- 从待办执行计划并写入养护记录时，把当时的计划名称快照和来源计划 id 写入记录。
- 养护记录、时间线、仪表盘最近养护、日历已完成，有名称时展示名称；没有名称的历史记录和手动添加的记录，仍展示任务类型。
- 待办到期计算：带有来源计划 id 的记录只推进那一条计划。没有来源 id 的旧记录仍按任务类型匹配，避免旧数据全部重新到期。

### 验收

- 两条同类型、不同名称的计划，完成其中一条后，对应养护记录显示该名称，另一条计划的下次到期日不因此被推进。
- 手动添加的养护记录仍显示类型标签。
- 未命名的旧计划在界面上仍显示原来的类型中文标签。

### 非目标

- 不删除任务类型字段。类型仍用于分类、AI 生成计划和旧记录匹配。
- 不要求 AI 生成接口返回自定义名称；确认添加时用类型中文标签作为初始名称，之后可编辑。
- 不改动生长记录。
